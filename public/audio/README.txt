Simone's voice for the phone call goes here.

  call.mp3   (or call.m4a / call.opus / call.ogg / call.wav — first one found is used)
             her reading the three lines in CALL.lines, src/content/personal.js

  call-decline.mp3  (optional) the ring-back lines in CALL.declineLines

A WhatsApp voice note works as-is: save it into this folder, rename to call.opus
(or whatever extension it has), commit, push. Without a file the call is text-only.
